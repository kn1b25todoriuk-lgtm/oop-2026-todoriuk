### Проєкт
`TravelApp` — консольний застосунок для початкового обліку туристичних пропозицій (турів) та клієнтів туристичної агенції[cite: 1].

### Структура проєкту
* `Models/Tour.cs` — клас для опису туру (Країна, Місто, Ціна)[cite: 1].
* `Models/Client.cs` — клас для опису клієнта (Ім'я)[cite: 1].
* `Program.cs` — точка входу в програму, де створюються об'єкти моделей та демонструється вивід інформації в консоль[cite: 1].
